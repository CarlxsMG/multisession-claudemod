# Getting help

- **Installing and using crew**: the [README](README.md) ([en español](README.es.md)).
- **A question**: ask in [Discussions, Q&A](https://github.com/CarlxsMG/multisession-claudemod/discussions/categories/q-a).
- **An idea, or something you built with crew**: [Discussions](https://github.com/CarlxsMG/multisession-claudemod/discussions).
- **A bug, or something you want crew to do**: open an issue with the **Bug report** or
  **Feature request** template.
- **A problem in Claude Code itself**, with crew turned off (`/plugin`): the
  [Claude Code issues](https://github.com/anthropics/claude-code/issues).
- **A vulnerability**: never in a public issue; see [SECURITY.md](SECURITY.md).
